Setup Instructions

Google Workspace Setup

  1. Go to the Google Cloud Console.
  2. Create a new project or select an existing one.
  3. Enable the Google Drive API, Docs API, Sheets API, and Slides API.
  4. Create a Service Account.
  5. Generate a JSON key for the Service Account.
  6. Paste the entire JSON content into the Google Service Account Key field.

Notion Integration Setup

  1. Go to Notion Integrations.
  2. Create a new integration.
  3. Copy the Integration Secret and paste it into the Notion API Key field.
  4. Share the Notion databases you want to access with the integration.

GitHub Integration Setup

  1. Go to GitHub Personal Access Tokens.
  2. Generate a new token with the required permissions (repo, project).
  3. Copy the token and paste it into the GitHub API Key field.

Universal Connector Setup

  1. Access the Universal Connector application.
  2. Create an account or log in.
  3. Generate an API key for this application.
  4. Configure the Universal Connector URL and API key in the form above.
  5. Store your API keys securely in the Universal Connector service.
